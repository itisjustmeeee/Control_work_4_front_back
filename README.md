# Control_work_4_front_back

> [!NOTE]
> Репозиторий для контрольной работы №4 по фронтэнд и бекэнд разработке

## Что представляют собой практики

1. В практике 19 была реализована работа с СУБД на примере PostgreSQL. Также в ней было реализовано создание нового пользователя, получение списка пользователей, получение конкретного пользователя по его id, обновление информации о определенном пользователе и удаление пользователя через SQL запросы с помощью pg непосредственно в коде.
2. В практике 20 была реализована работа с NoSQL СУБД на примере MongoDB. Также в ней было реализовано создание сущности "Пользователя", создание нового пользователя, получение списка пользователей, получение конкретного пользователя с помощью его id, обновление информации о конкретном пользователе и удаление пользователя с помощью mongoose, который позволяет работать с MongoDB непосредственно в коде.
3. В практике 21 было реализованое кэширование с использованием Redis - NoSQL системы для управления базами данных. Также в ней было реализовано хранение кеша о списке всех пользователей и получении конкретного пользователя в базе данных Redis с временем хранения равным 1 минуте и хранение кеша о списке всех товаров и получение определенного товара в базе данных Redis с временем хранения равным 10 минутам.
4. В практике 22, в которую входит практика 23, была реализована работа с Docker, его установка на устройство, настройка и использование в практиках для создания контейнеризации приложения и балансировки нагрузки в веб-приложении. Также в ней была реализована тестовая система балансировки нагрузки для веб-приложения. Было подготовлено 3 backend-сервера, работающих на разных портах, настроен Nginx как балансировщик нагрузки, добавлены настройки отказоустойчивости через max_fails и fail_timeout. Также был настроен аналогичный файл для балансировки через HAProxy.

## Установка и запуск практик

### Практика 19

1. **Запустить сервер PostgreSQL, чтобы он работал в фоновом режиме (это необходимо для успешного подключения программы к базе данных и дальнейшей работы с ней)**
2. Запустить работу сервера:
```
node server.js
```

### Практика 20

1. **Запустить сервер MongoDB для работой с базой данных**
в терминале (cmd)
```
mongosh
```
2. Запустить работу сервера:
```
node server.js
```

### Практика 21

1. Запустить работу Docker:
```
docker run -d -p 6379:6379 redis
```
2. Запустить работу сервера:
```
node server.js
```

### Практики 22-23

1. Запустить работу Docker:
**при первом запуске:**
```
docker compose up --build
```

**при повторном запуске:**
```
docker compose up
```
